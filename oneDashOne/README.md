# oneDashOne - Demonstração projeto GameMaker

Um projeto de demonstração desenvolvido no GameMaker, recriando a clássica fase 1-1 de Super Mario Bros. Um projeto da IFtechJR

<br/>

## Sobre o projeto

Projeto educacional e de demonstração.
Este projeto é um jogo de demonstração sobre lógica de programação aplicada em Game Dev.

<br/>

A proposta é aprender lógica de código de forma "gameficada", imitando a primeira fase do clássico Super Mario Bros. Um simples jogo de plataforma, que explora conceitos como:

- Movimentação do personagem;

- Pulo e física básica;

- Colisão com plataformas;

- Inimigos;

- Coleta de itens;

- Câmera acompanhando o jogador;

- Estruturação de uma fase 2D;

- Interações entre jogador, inimigos e cenário.


<br/>

## Gameplay

A demonstração apresenta uma fase inspirada na 1-1 do jogo citado, contendo elementos simples de jogos de plataforma 2D, como plataformas, obstáculos, inimigos e itens coletáveis.

O objetivo principal é chegar ao final da fase enquanto o jogador interage com os elementos do cenário.

<br/>

## Tecnologias

GameMaker

GML (GameMaker Language)

Física e sistema de colisão própria

<br/>

## Guia rápido de como configurar GameMaker com GitHub no Windows

Baixe o instalador no site https://gamemaker.io/pt-BR/download

Abra o .exe e siga as instruções

Abra o GameMaker

Baixe o repositório do GitHub

No GameMaker clique em "Abrir" 

Navegue até a pasta em que você baixou o repositório

Selecione o arquivo "oneDashOne.ypp"

Você verá o projeto na sua tela
